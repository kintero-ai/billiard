# 🎱 Бильярд 8

Браузерная игра в бильярд для ПК и смартфона: **пул «Восьмёрка»** и **русский бильярд «Американка»**. Без установки и зависимостей: чистый HTML5 Canvas + JavaScript.

**Играть:** https://kintero-ai.github.io/billiard/  
или просто откройте `index.html` в браузере.

## Режимы
- **Против компьютера** — бот выбирает лучший удар в лузу, умеет ставить «шар в руке».
- **2 игрока** — по очереди на одном устройстве.

## Правила: пул «Восьмёрка»
- Разбивка, затем группа (сплошные 1–7 или полосатые 9–15) назначается первым забитым шаром.
- Забили свой шар — бьёте ещё раз.
- Фол (биток в лузе, первым задет чужой шар, ни один шар не задет) — соперник получает «шар в руке».
- Побеждает тот, кто после своей группы забьёт чёрную восьмёрку. Забить её раньше или с фолом — проигрыш.

## Правила: русский бильярд «Американка»
- 16 одинаковых шаров цвета слоновой кости, узкие лузы. Побеждает тот, кто первым забьёт **8 шаров**.
- Разбивка — битком без номера из «дома» (зона слева от линии).
- Дальше бить можно **любым шаром по любому**; засчитывается любой забитый шар, в том числе сам биток («свояк»).
- Забили — бьёте ещё раз, не забили — ход переходит сопернику.
- Фол — биток никого не задел: забитое этим ударом возвращается на стол, один шар нарушителя снимается штрафом, ход переходит сопернику.
- Выбрать шар, которым бить: кнопка ◎ и касание шара, или двойной клик/касание по нему.

## Управление
| | ПК | Смартфон |
|---|---|---|
| Прицел | движение мыши, ← → (Shift — точнее) | касание стола, кнопки ⟲ ⟳ |
| Удар | зажать кнопку мыши, оттянуть назад, отпустить; или ↑ ↓ + пробел | провести по полосе «СИЛА» и отпустить |
| Шар в руке | перетащить биток | перетащить биток |

На телефоне в портретной ориентации стол поворачивается вертикально; кнопка ⛶ включает полноэкранный режим.

## Структура
```
index.html      разметка, меню
style.css       адаптивная вёрстка
js/physics.js   физика шаров, борта, лузы
js/rules.js     правила 8-ball
js/ai.js        компьютерный соперник
js/render.js    отрисовка стола, шаров, кия
js/input.js     мышь, касания, клавиатура
js/main.js      игровой цикл, HUD, звук
```
